# Tidepool-QC

A quality-control pipeline that flags batch effects in multi-site clinical laboratory datasets before downstream modelling.

## Repository Status

**Released** — this repository contains the reference implementation described in
doi:10.1080/jclininf.2026.04417. The source code is publicly available under the MIT
License and is ready for external use.

## Contents

- `src/` — reference implementation
- `data/` — schema definitions
- `experiments/` — configuration files
- `notebooks/` — exploratory notebooks
- `results/` — aggregated results
- `tests/` — smoke tests
